# MAS-PRO

**MAS-PRO** is a university project developed for the **Modeling and Analysis of Systems (MAS)** course. The project focuses on applying UML modeling principles and object-oriented design concepts to the development of a software system.

## 📋 Project Information

|                      |                                        |
| -------------------- | -------------------------------------- |

| **Type**             | University Project                     |
| **Primary Language** | C#                                     |
| **Frontend**         | HTML / CSS / Blazor                    |
| **Status**           | Active Development                     |
| **Author**           | Artiom Bezkorovainyi (s30174)          |

## 📐 UML Requirements

The project is developed according to the UML requirements provided for the course.

The complete requirements and design specifications are available in the official document:

**[UML Requirements Specification](https://drive.google.com/file/d/1H25Sa5P4k2u6P9iH58dovP91WGcp05tk/view?usp=sharing)**

The specification contains information about:

* Class diagrams
* Use case diagrams
* Sequence diagrams
* System architecture
* Class relationships and associations
* Design patterns
* Other UML modeling requirements

## 🏗️ Architecture

The system is designed following the principles and requirements defined by the UML specification.

The project emphasizes:

* Clear class hierarchies and relationships
* Separation of responsibilities
* Object-oriented design principles
* Well-defined system components
* Proper interactions between system elements
* UML-compliant architecture and documentation

## 🚀 Getting Started

### Prerequisites

To build and run the project, you will need:

* A compatible **.NET SDK**
* **Visual Studio**, **JetBrains Rider**, or another C#-compatible IDE
* Git

### Installation

1. Clone the repository:

```bash
git clone https://github.com/YAUIO/MAS-PRO.git
```

2. Navigate to the project directory:

```bash
cd MAS-PRO
```

3. Open the solution/project in your preferred C# IDE.

4. Restore dependencies and build the project.

5. Run the application according to the project's configuration.

## 📁 Project Structure
